# FrameForge 像素工具箱

一站式像素游戏素材处理工具箱（frameronin.com v5.0 的功能复刻版），采用 **Rust + WebAssembly** 高性能内核，全部处理在浏览器本地完成，**数据不出本机**。已移除原站所有广告推广类内容（充值、代充说明、推广悬浮按钮、外链广告等）。

![模块](https://img.shields.io/badge/%E6%A8%A1%E5%9D%97-31%E4%B8%AA%E8%B7%AF%E7%94%B1-b64a2e) ![内核](https://img.shields.io/badge/WASM-104KB-4a7c59)

## 快速开始（推荐：双击 exe）

**双击项目根目录的 `FrameForge.exe`** —— 完事。它会：

1. 自动探测端口（8123 被占则依次尝试到 8140）
2. 启动内置 HTTP 服务（**全部网页资源已嵌入 exe，单文件即可分发**）
3. 自动打开默认浏览器

保持黑色控制台窗口开着即可（关掉窗口 = 停止服务）。exe 约 1.1MB，无任何外部依赖，拷到别的 Windows 电脑也能直接用。

```powershell
# 重新构建 exe（改了 web/ 资源后需要）
cd server && cargo build --release
copy target\release\frameforge-server.exe ..\FrameForge.exe
```

## AI 配置（支持自定义 API / 中转站）

1. 顶栏「**API 设置**」→ 填写 **API 地址** + **Key** → 保存（可先"测试连接"）
2. **Z** 进入自由生图或任意 AI 页面生成；结果可下载、存暂存、转画布参考

### 支持三种协议（自动识别，也可手动指定）

| 协议 | 适用 | 地址写法（均可识别） |
|---|---|---|
| **Gemini 原生** | Google 官方 / Gemini 格式中转 | `https://generativelanguage.googleapis.com`、`https://xxx/v1beta`、完整 `…/models/gemini-…:generateContent` |
| **OpenAI 兼容 · Chat** | OneAPI/NewAPI 等中转站 | `https://xxx`、`https://xxx/v1`、`https://xxx/v1/chat/completions` |
| **OpenAI 兼容 · Images** | `/v1/images/generations` 类 | `https://xxx`、`https://xxx/v1`（图生图自动走 `images/edits` multipart） |

- Key/地址仅存本机 localStorage；请求浏览器直连目标服务，无中间服务器
- `server.js` 内置 `/mock/*` 模拟端点，可在无真实 Key 时自测三协议链路

## 架构

```
├── wasm/                  Rust 内核 crate（原生 extern "C" 导出，无 bindgen）
│   └── src/lib.rs         色键/像素化/量化/HSV调整/内描边/Sheet合成拆分/GIF编解码/双背景差分
├── web/
│   ├── index.html         SPA 外壳（hash 路由）
│   ├── css/style.css      深浅双主题（CSS 变量）
│   ├── js/
│   │   ├── main.js        路由/首页/快捷键/主题/弹窗/API设置
│   │   ├── i18n.js        中/EN 词典
│   │   ├── ai.js          Gemini API 直连 + Key 管理 + 预设/历史
│   │   ├── stash.js       全站暂存侧栏
│   │   ├── wasm.js        Worker 池 + Promise 封装
│   │   ├── worker.js      WASM 加载与执行（可多实例并行）
│   │   ├── zip.js         零依赖 ZIP 打包（store）
│   │   ├── ui.js          组件库（步骤条/上传区/滑杆/胶片条/对比视图/灯箱…）
│   │   ├── lib/lame.min.js  MP3 编码器（lamejs, MIT）
│   │   └── tools/         21 个工具页（freegen/aihub/lab/proplus/rseprite/info…）
│   └── wasm/core.wasm     构建产物（~104KB）
├── server.js              零依赖静态服务器（正确 MIME: application/wasm）
└── build.sh / build.ps1   cargo build + 复制产物
```

**性能设计**：像素级运算（色键、量化、Floyd-Steinberg 抖动、GIF LZW）全部在 WASM 内完成；Worker 池（按 CPU 数量）并行处理帧序列，主线程零阻塞；内存经 `ff_alloc` 手动管理，帧数据以 Transferable 零拷贝往返。

## 说明

- 视频提取依赖浏览器原生解码能力（MP4/WebM 等浏览器可解码格式）。
- 原站的 Gemini 水印去除 / Seedance 视频去水印 / rembg 服务端抠图依赖后端或涉及去水印合规，未纳入。
- 原站 AI 生成模块（RpgMaker 角色生成/完美八方向/自由序列等）在原站需付费代充后端，本工具箱以**本地 API 直连 + 提示词预设**实现同等工作流。
- 原站的 iframe 外挂应用（RoninTile 全屏版/OpenTerrain/RoninCut/SkelForm/建筑生成器/NPC 资源库/地形插件/HD2D 优化器）为独立大型 Web 应用，本工具箱提供等价的本地实现或直达外链说明页。
